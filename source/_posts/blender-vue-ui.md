# Blender+Vue 复刻《明日方舟》官网 3D 交互 UI

浏览明日方舟官网，工业风、 3D 悬浮交互的 UI 总能让人眼前一亮。鼠标划过时模型局部泛起全息蓝光，并伴随着精准的 UI 边框锁定。
一开始以为这需要引入 Three.js，在前端实时渲染 3D 模型。实际做下来，这个固定视角的页面可以用预渲染图片实现：在 Blender 中生成底图和高亮图层，再交给 Vue 处理交互。
这篇博客将完整记录如何利用开源 3D 模型，结合 Blender 和 Vue 3，从零搭建出这个交互页面的全过程，以及期间踩过的性能与渲染大坑。

---

##  第一阶段：Blender 里的伪 3D

UI再炫酷，也需要资产基底。这一步的核心目的只有两个：**强制统一画风**与**分离交互图层**。

### 1.使用正交摄像机

使用开源素材搭好场景后，遇到的第一个反直觉设定是摄像机。

- **原理**：人类肉眼习惯透视产生的近大远小，但在科技风UI中，则需要的是绝对平行。
- **操作**：将摄像机切换为 **正交 (Orthographic)** 模式，通过 `Orthographic Scale` 调整画面缩放。底图和高亮图层使用相同的摄像机参数、构图和输出尺寸，让模型轮廓在叠加时对齐。

### 2. 剥离贴图，建立“高级灰”

尝试时发现开源模型自带的木纹、粉色霓虹灯在同一个画面里会引发严重的“画风割裂”。

- **操作**：剥离所有原生材质，统一赋予自调的 `M_Base_Grey`（低金属度 0.3，高粗糙度 0.7）。
- **避坑**：粗糙度降到 0 后，镜面反射会更突出。这个场景的环境较暗，使用较高的粗糙度能让模型轮廓和明暗变化更清楚。

### 3.Holdout与透明分离

整个项目最重要的 3D 原理就在于此。为了实现点击交互，需要输出两张图：

1. **纯灰底图**
2. **只有高亮物体（带有蓝色发光和桌面反光）的透明图**
   高亮层还需要保留桌面对模型的遮挡。直接隐藏桌子，会让原本埋在桌面下的模型部分出现在透明图中，叠加后与底图对不上。
- **解法**：在 View Layers 中，将桌子所在的集合设置为 **Holdout**。
- **原理**：Holdout 将桌子遮住的区域从高亮层中扣除，使其成为透明区域。导出的 PNG 保留了模型被桌面遮挡后的轮廓，叠加到底图时，两层的遮挡关系就能一致。

##  第二阶段：Vue 3 前端重构与事件流陷阱

拿到美术资产后，切回 VS Code。核心思路是用 CSS 的 `position: absolute` 。

### 1. The Z-Index Sandwich

- **底层**：全灰的底图 (`z-index: 1`)。
- **中层**：带有 Alpha 通道的高亮特效 PNG (`z-index: 10`)。
- **顶层**：用纯 HTML/CSS 写的白色精准定位框和蓝色色块 (`z-index: 20`)。
  将 UI 装饰（白框/文字）交给 DOM 渲染，不仅保证了无极缩放时的矢量清晰度，还能轻松加上 CSS 过渡动画（Transition）。

### 2. 物理穿透：`pointer-events: none`

由于顶层的白色 UI 边框盖在了高亮图层上面，在测试点击切换时，遇到了经典的 DOM 事件流遮挡问题：鼠标点到了白框上，底下的交互逻辑根本触发不了。

- **原理**：`event.target` 判定被最上层元素拦截。
- **最后**：给 UI 框加上 `pointer-events: none;`。

##  第三阶段： 动态计算 vs 预编译

在实现UI 边框精准套住高亮发光模型，发现有两种解法

### 方案一：Canvas Alpha 像素扫描

起初用了一套纯 JS 算法：在图片 `@load` 时用离屏 `<canvas>` 获取 `getImageData`，遍历所有的 rgba 数组。通过设置 Alpha 阈值（`Alpha > 30` 过滤掉微弱泛光），动态计算出模型的最小包围盒（Bounding Box），并转化为百分比赋给白框。

- **不足**：这套方案极度消耗主线程。实测在切换侧边栏时，由于要瞬间遍历几百万个像素，出现了大约 3 秒的严重卡顿和延迟。

### 方案二：设计软件测量法

与其让成千上万的客户端去重复计算一个永远不会变的静态坐标，不如把计算前置。

- **最终方案**：直接在 Figma/Photoshop 里量出百分比位置，硬编码写死在 JSON 数据里。
- **开销变化**：客户端直接读取预先测好的坐标，省去了图片加载后遍历像素、计算包围盒的过程。固定图层的位置在制作素材时确定，页面运行时负责显示和交互。

优秀的前端交互也可以借助图形学底层逻辑，不必只死磕 CSS 动画或 JS 框架。通过 Blender 自动化管线处理光影遮挡，再用 DOM 处理事件交互，关注点分离的思想贯穿始终。
